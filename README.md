# Noon Commander Tap

## How do I install these formulae?

`brew install noon-commander/tap/<formula>`

Or `brew tap noon-commander/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "noon-commander/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
